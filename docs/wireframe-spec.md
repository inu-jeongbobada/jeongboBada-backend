# 정보바다 기능 요약 (와이어프레임 기준)

> 기획(와이어프레임)의 요구사항 원본. 괄호 안 번호는 와이어프레임 화면 번호다.
> 백엔드에서 실제로 어떻게 구현했는지(에러 코드, 저장 방식 등)는 `docs/{도메인}-architecture.md`에 적는다.
> 와이어프레임이 바뀌면 이 문서도 같이 고친다.

- 서비스: 인천대학교 정보통신학과 강의 정보·수강 후기 공유 웹 서비스
- 해상도: 1440 × 1800 (Desktop)
- GNB: 홈 / 교수님 정보 / 전공 강의평 / 마이페이지
- 접근 권한
  - 비로그인: 홈, 강의 목록·검색
  - 로그인 필수: 강의 상세, 후기, 학습자료
- 공통 정책
  - 로그인 만료 시 → 로그인 안내(17번) → 재로그인 후 요청 화면 복귀
  - 등록·저장 처리 중 중복 제출 방지
  - 실패 시 입력 내용 유지 + 다시 시도 제공

---

## 1. 회원가입

- 입력 항목
  - 닉네임: 2~6자, 한글·영문·숫자 / 중복 확인 필수
  - 이메일: 학교 메일 (`@inu.ac.kr`) / 형식·중복 검사
  - 학번: 형식·중복 검사 (ex. 202301589)
  - 비밀번호: 8자 이상, 영문·숫자 포함 / 확인 일치 검사
  - 신분 확인 서류: pdf·jpg, 최대 10MB, 1개
    - 인정 서류: 재학증명서, 학생증, 성적증명서, 학비 납입 증명서, 졸업 예정 증명서
    - 안내: 이름·학번 식별 가능, 주민번호 등 불필요 정보 가림, 승인 후 서류 즉시 삭제
- 검증 상태: 필수 항목 미입력, 파일 형식 오류, 용량 초과, 업로드 완료, 모두 입력 완료
- 가입 신청 완료 → 운영진 서류 검토 (보통 1~2일) → 결과 이메일 안내
- 작성 중 이탈 확인 팝업
- 가입 반려 시: 반려 사유 표시 → 서류 다시 올리기 → 재제출

## 2. 로그인

- 학번 + 비밀번호
- 오류 처리: 빈칸 제출, 학번 형식 오류, 학번·비밀번호 불일치, 미가입 학번
- 5회 실패 → 5분 잠금 (남은 시간 표시, 비밀번호 찾기 유도)
- 계정 상태별 팝업
  - 가입 승인 대기: 신청일 표시, 카카오톡 오픈채팅 문의
  - 가입 반려: 반려 사유 표시, 서류 다시 올리기
- 네트워크 오류(502) / 로딩 / 복구 상태

## 3. 비밀번호 찾기·재설정

- 이메일 입력 → 인증번호 발송
  - 오류: 빈칸, 이메일 형식 오류, 일치 정보 없음
- 인증번호 입력: 유효시간 5분
  - 불일치, 5회 실패, 시간 만료, 재발송 완료 + 메일 미수신 안내
- 비밀번호 재설정
  - 확인 불일치, 이전 비밀번호와 동일 불가
  - 완료 → 로그인 화면

## 4. 홈 (1번)

- 강의명·교수명 검색
- 필터: 학년 / 전공 종류 / 학점 / 교수
- 메뉴 카드: 강의 정보(전체 강의 조회), 시간표·졸업 관리(2차 배포·준비 중)
- 인기 강의 카드 + 전체보기(평점순 목록)
- 하단 배너: 서비스 소개

## 5. 강의 목록·검색 (2~16, 21번)

- 기본 정렬: 이름순 / 선택: 이름순·평점순
- 필터 적용·초기화, 필터 유지한 채 재검색
- 검색: 강의명·교수명, 검색어 굵게 강조, 초성 검색 지원
- 빈 검색어 → 전체 강의 조회
- 무한 스크롤 (추가 로딩 / 마지막 강의 도달 안내)
- 상태: 검색 중, 결과 없음(검색어 변경·필터 초기화 안내), 조회 실패(다시 시도)
- 강의 선택 시 로그인 여부 확인 → 비로그인이면 17번 로그인 안내
  - 로그인 후 선택 강의 상세로 이동, 검색어·필터·정렬·스크롤 위치 유지

## 6. 강의 상세 – 정보·후기 (18~30번)

- 강의 기본 정보: 강의명, 교수, 학년, 전공 구분, 학점, 평점
- 탭: 강의 정보·후기 / 학습자료 / 강의 비교(준비 중) / 강의 조합(준비 중)
- 강의 소개
- 강의 리뷰 요약: 평점, 시험 난이도, 과제 난이도, 조모임, 출결, 총 후기 수 등
  - 후기 부족 시 "요약 데이터 부족" 상태
- 후기 목록
  - 익명 / 수강학기 / 평점 / 내용 / 공감 수
  - 정렬: 최신순·추천순(공감)·별점순
  - 내 후기 맨 위 고정 + 수정·삭제 버튼
  - 공감, 신고 (신고 확인 → 접수 완료 / 실패)
  - 후기 더 보기, 추가 로딩 실패 처리
  - 후기 없음: 빈 안내 + 후기 작성 진입

## 7. 후기 전체 조회 (31~38번)

- 후기만 모은 전체 목록 (탭 없음, 강의 상세 복귀 버튼)
- 정렬: 최신순·추천순·별점순 / 내 후기 항상 맨 위
- 내 후기 수정·삭제, 삭제 후 총 후기 수 갱신

## 8. 후기 작성 (39~93번)

- 익명 공개
- 필수 항목

  | 항목 | 선택지 |
  |---|---|
  | 평점 | 1~5 |
  | 수강학기 | 연도 + 1학기·여름학기·2학기·겨울학기 |
  | 수업 진행 방식 | 드롭다운 |
  | 전공서적 사용 | 필수·선택·미사용 |
  | 시험 난이도 | 1~5 / 시험 없음 |
  | 과제 난이도 | 1~5 / 과제 없음 |
  | 과제량 | 1~5 / 과제 없음 |
  | 온라인 수업 비중 | 대면·혼합·온라인 |
  | 조모임 여부 | 있음·없음 |
  | 출결 관리 방식 | 드롭다운 |
  | 시험 횟수 | 없음·1회·2회·3회·4회 이상 |
  | 퀴즈 빈도 | 없음·학기 1~2회·월 1~2회·매주 |
  | 퀴즈 난이도 | 1~5 / 퀴즈 없음 |
  | 학점 부여 성향 | 1(너그러움)~5(깐깐함) |
  | 수강 후기 | 20~1000자 |

- 연동 규칙: 시험·과제·퀴즈 "없음" 선택 시 관련 항목 자동 "없음" 처리
- 검증: 빈칸 제출, 평점 미선택, 수강학기 미선택, 필수 선택 누락, 20자 미만, 1000자 도달(초과 입력 차단)
- 등록 처리 중 / 완료(내 후기 맨 위 확인) / 실패
- 작성 중 이탈 확인, 작성 중 로그인 만료 → 재로그인 후 작성 화면 복귀

## 9. 내 후기 수정·삭제 (94~103번)

- 수정: 기존 내용 채워서 표시, 작성과 동일 조건, 저장 중 / 완료 / 실패 / 취소 확인
- 삭제: 확인 → 처리 중 → 완료(후기 수 갱신) / 실패

## 10. 학습자료 (104~121번)

- 목록: 자료 제목, 형식, 등록일, 다운로드 / 무한 스크롤
  - 제목 클릭 시 상세 진입
  - 닉네임 칼럼 + 삭제 버튼, 내 글 맨 위 고정
- 상태: 불러오는 중, 등록된 자료 없음(업로드 진입점), 조회 실패
- 업로드
  - 제목 5~50자 / 설명 10~500자 / 자료 유형 1개 이상(복수 선택) / 첨부 파일 1개
  - 자료 유형: 강의 필기, 개념·요약 정리, 문제·풀이, 기타
  - 검증: 조건 미달, 제목·설명 글자수, 유형 미선택, 파일 누락
  - 등록 처리 중 / 완료 / 실패 / 작성 취소 확인
- 상세: 제목, 유형, 작성자(닉네임), 등록일, 수정일, 설명, 첨부 파일(파일명·형식·크기) 다운로드

---

## 확인 필요 사항

- 후기 수정(94~99번)이 흐리게 처리됨 → 수정 기능 제외 여부 확인
- "후기 삭제 불가, 등록 시 삭제 불가 안내 필요" 메모 ↔ 삭제 화면(100~103번) 존재 → 삭제 정책 확정 필요
- 학습자료 상세 → "상세 보기" 버튼을 "다운로드"로 교체, 제목 클릭으로 상세 진입 (개정 메모)
- 수업 진행 방식·출결 관리 방식 선택지 값 미정
- 학습자료 허용 파일 형식·용량 미정
- 교수님 정보 메뉴 화면 없음
